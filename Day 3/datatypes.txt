DATA TYPES

Python is dynamically typed so no need to represent specifically
1.Numerical datatypes: int,float,complex #all are immutable
    complex:known for imaginary numbers such as 3+5j
2.Sequential datatypes: str,list,tuple  #except list remaining both are immutable
    i.str:collection of characters enclosed between single qoutes or double quotes and it is immutable
    s="codegnan"
    ii.list:collection of elements enclosed between [] and it is a heterogenous datatype which can store elements of any datatype
    It is ordered, allows duplicates and mutable
    k=[1,2,3.4,8]
    iii.tuple:collection of elements enclosed between (), heterogenous, ordered, allows duplicates and immutable  #list and tuple has same features but the elements in the tuple are not modifiable
    t=(1,2,3.4,'a')
    
'''MUTABLE:when we can change the elements such as add,delete,modify in the same memory referance
IMMUTABLE:when we are changing the elements it will not have same memory references'''

3.Mapping datatypes:set,dict #both are mutable
    i.set:collection of unique elements enclosed between {}. It is unordered, does not allow duplicates and mutable
    s={123,43,56,233}
    ii.dict:collection of key-value pairs and it is mutable and ordered
    d={1:"one",2:4,3:[1,2,3],5:(1,2,3)}
4.Boolean datatype:it shows either True or False    #mutable
    status = True
    s = False
5.None datatype:it is used when we are not specific about the memory space required
    s = None
