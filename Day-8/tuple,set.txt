TUPLE

Properties
    1.immutable,ordered,allows duplicates, heterogenous, dynamic
    2.packing and unpacking such as a, b, c=(1,2,3)
    3.as tuple is an immutable datatype we cannot change the elements or make modifications to the tuple but it has mutable elements such as list,set and dict then we can make changes to them


OPERATIONS:
    1.Concatenation
    2.Repetition
    3.Indexing
    4.Slicing
    5.Membership

Methods:
    1.len()
    2.sorted()
    3.max()
    4.min()
    5.count()
    6.index()
    7.any()
    8.all()
    9.sum()




SET

Properties:
    1.mutable,unorderd,allows unique values ,heterogenous, dynamic
    2.we cannot declare a set with curly braces such as {} bcoz it take it as dict
    3.we need to declare set with set()
    4.set is heterogenous but it allows only immutable elements.It does not allow elements such as list, set, dict
    5.it does not allow concatenation, repetition, indexing, slicing


Operations:
    1.union: represented as |
    2.intersection: represented as & and output is the common elements
    3.symmetric difference: represented as ^ and output is the elements which are not common
    4.difference:represented as -
    5.membership
    6.isdisjoint():checks whether the 2 sets have common elements or not
    7.issuperset()
    8.issubset()

Methods:
    1.sorted()
    2.max()
    3.min()
    4.len()
    5.sum()
    6.all()
    7.any()
Modifying elements:
     1.add():is used to add single element
     2.update():is used to add multiple elements
     3.pop():is used to delete some random elements
     4.remove():is used to delete particular element and when that element is not present in the set then it will throw the error
     5.discard():is used to avoid raising errors when the particular element is not present in the set so it just executes
     6.clear():is used to delete or clear all the elements in the set
     7.copy()



Frozen set:
     It has all properties such as set but it is immutable
     s=frozenset({1,23,4})
